# Сайт АНО РСЗИ «Триумф»

Сайт автономной некоммерческой организации развития социально-значимых инициатив «Триумф», село Раевский Альшеевского района Республики Башкортостан.

Сайт статический. Ему не нужен сервер, база данных и программисты, поэтому он живёт прямо на GitHub Pages.

## Что где лежит

| Файл или папка | Что это |
|---|---|
| `index.html` и другие файлы `.html` | каркасы страниц, текста в них почти нет |
| `data.js` | все тексты, фотографии, ссылки и реквизиты сайта |
| `assets/app.js` | собирает страницы из данных |
| `assets/style.css` | оформление, цвета и шрифты |
| `img/` | фотографии проектов, фильмов, людей и партнёров |
| `docs/` | сюда кладут PDF публичных отчётов |
| `404.html` | страница на случай неверного адреса |
| `.nojekyll` | просит GitHub отдавать файлы как есть |

## Как поменять текст или фотографию

Почти всё живёт в файле `data.js`. Нужную строку правят между кавычками, сохраняют файл и отправляют изменение на GitHub. Сайт обновится сам за минуту или две.

Новую фотографию кладут в папку `img` и пишут путь к ней в `data.js`, например `img/projects/название.jpg`.

Правила текстов простые. Пишем живым человеческим языком, без тире и двоеточий. Фильмы называем полностью, например «Документально-художественный фильм «Александр Фёдорович Раев»». Имя директора везде пишем полностью, Гридина Татьяна Николаевна.

## Как посмотреть сайт у себя на компьютере

Открыть `index.html` двойным щелчком мало, браузер запретит читать `data.js`. Нужен простой местный сервер. Если на компьютере стоит Python, в папке сайта выполняют команду

```
python -m http.server 5173
```

и открывают в браузере адрес `http://localhost:5173`.

## Публичный отчёт

Готовый PDF лежит в `docs/otchet-triumf-2023-2025.pdf` и уже виден на странице «Отчёты». Собирается он отдельно, из папки `report` в рабочем проекте на компьютере. Если выйдет новая версия, файл кладут в `docs` под тем же именем, и на сайте ничего менять не нужно.
