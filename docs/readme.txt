Здесь лежат документы, которые видны на странице «Документы».

Сейчас это:

  ustav-ano-triumf-2024.pdf      устав организации
  vypiska-egrul-2026.pdf         выписка из ЕГРЮЛ
  otchet-triumf-2023-2025.pdf    публичный отчёт с 2023 по 2025 год
  opros-turizm-kultura-2026.pdf  опрос жителей Альшеевского района
  opros-istoriya-kraya-2026.pdf  опрос об истории родного края

Сама страница собирается из файла data.js, из раздела docsPage. Там три
блока: реквизиты, публичные отчёты и исследования. Чтобы добавить новый
документ, кладут файл сюда и дописывают его в нужный блок четыре строки:
title название на странице, file путь к файлу, saveAs имя для сохранения,
meta подпись вроде «PDF, 8 страниц, февраль 2026 года».

Имена файлов пишем латиницей, без пробелов, так надёжнее для ссылок.
Если новая версия отчёта выходит под тем же именем, на сайте менять
ничего не нужно.
