Здесь лежат PDF публичных отчётов организации.

Сейчас это otchet-triumf-2023-2025.pdf, публичный отчёт с 2023 по 2025 год.
Страница «Отчёты» берёт его из файла data.js, из раздела reportsPage.

Если выйдет новая версия отчёта, проще всего положить её сюда под тем же
именем, тогда на сайте ничего править не придётся. Если имя другое, его
пишут в data.js в строке file, а в строке saveAs указывают, под каким
именем файл сохранится у человека.
